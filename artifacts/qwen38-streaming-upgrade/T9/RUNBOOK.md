# Deferred hardware qualification

T9 is blocked by the explicit instruction to defer server startup and hardware
execution. This package does not grant device access or start a service. The
compiled candidate and all offline receipts remain unqualified.

## Before device access

Resolve reference-v2.json into a new append-only reference revision: exact
checkpoint files, installed serving OPP/bridge/native binaries, tokenizer/model
IDs, token IDs and rendered requests for every defined trial. Freeze fresh image
bytes and image processor settings. Historical timing is comparison context,
not a current runtime identity or thermally qualified baseline.

Create a new bundle version from the final committed tree with configuration.json.
Do not edit or rebuild an existing bundle. Verify all sources, compiled byte
identities, target/ABI metadata and auxiliary kernels. Candidate, configuration,
resource and source changes invalidate dependent evidence. Freeze the worker
import root before startup; file hashes alone cannot authenticate already imported
code objects. Do not replace files underneath loaded workers.

The supplied controller is an offline-first injectable transaction, not an HTTP
client or a ready stock-worker extension. Bind WorkerTransaction callbacks to
owned original hooks, metadata-only preparation, admitted loading/install and
saved undo. A scheduler adapter must establish an exclusive maintenance lease,
actual request/queue state, complete four-rank RPC completion and temperatures.
Stock pause endpoints and status responses alone do not establish these proofs.
Do not enable the live path until these adapters and all admission evidence agree.

Admission requires complete source/native/gate/trial artifact bytes, expanded
external Git source inventories, matched rank PIDs/storage/generation/plan and
explicit per-rank memory envelopes. Include simultaneously resident baseline/new
resources, graphs, caches, state archives, HCCL and shadow/verification scratch.
Measured builtin/backend scratch cannot be substituted with zero. Unknown bytes
or insufficient headroom are a stop condition before allocations.

## With renewed hardware authorization

Serialize production-shape kernel tests first. Verify paired limb layout, FP32
correction/group order, FP16 device rounding, slot acquisition, CO1 readback and
release, changing inputs, peer zeros and window tails. Host compilation and CPU
stubs prove neither asynchronous events nor physical overlap. Use actual loaded
namespace/binary receipts on all four ranks.

Run shadow real activations/routes against identical checkpoint expert banks,
then full model quality, tool, fresh/cached image, cache/CoW, EP, MTP0/1/2 and
changed-input graph replay gates. Preserve sparse decode and W8A16 draft paths.
Smaller communication chunks are separate configurations and require new whole
MoE arithmetic checks; the reference 2560 batch gives one default chunk.

Keep capacity and image processing fixed. Run at least three ABBA cycles for the
primary workloads with identical token IDs, warmups, output limits and cold/warm
cache policy. Report cold TTFT/prefill, warm TTFT, completion, decode/mixed service,
rank skew, memory and holding time. Profile attribution in separate runs; logical
payloads are not bus traffic. Record DMA/casts/layouts/events/HCCL and temperature
together. Thermal rise alone does not identify which transfers caused it.

Enforce hold at any core >=94C, resume only when all cores <=85C, and the existing
independent 96C cutoff. Missing sensors/controller enforcement stop testing. Do
not switch candidates or recapture during a thermal hold. Do not restart a server,
evict active requests, reduce capacity or bypass the cutoff to pass a gate.

Promotion requires complete matched evidence. Seek 10% primary improvement; any
smaller gain must exceed the plan's repeatability threshold. Reject repeatable
decode/mixed regressions above 5%, capacity loss, or thermal cutoff. No measured
speedup or thermal reduction follows from this offline package.
