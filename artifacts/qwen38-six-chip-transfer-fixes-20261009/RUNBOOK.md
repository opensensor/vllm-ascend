Before full-model timing, require:

1. Raw strided-state parity and changed-input graph replay, including cold state,
   nonadjacent slots and untouched physical padding.
2. Six-rank startup, shared partial contribution exactly once, all-reduce
   participation, actual live head weights and equal scheduler cache descriptors.
3. Real-weight text/image output and state parity, cached requests, prefix CoW,
   cancellation and cache rebinding. Do not carry old padded-page encodings across
   the change; fresh workers and empty caches are required.
4. Per-rank memory peaks including NZ alignment, retained uniform cache reserve,
   vision, graphs/HCCL, checkpoint tiers, allocator and prefill scratch.
5. Paired TTFT/decode/mixed-load timing plus host↔NPU, device-local DMA, HCCL and
   barrier traces on the same clock as temperatures and thermal holds. Report
   completed tokens and physical transfer counts; logical byte formulas are not
   hardware counters. Preserve image processing and the existing thermal policy.
