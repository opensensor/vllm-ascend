# GLM 运行与恢复

使用原 FP16 scale 检查点、CANN 9.1.0 与四张 310P，端口仍为 8001。
完整构建命令和恢复控制器保存在 measurements 压缩包中。

1. 按原父版本全部参数构建 v992–v995，增量启用读回事件或批量路由 DMA。
2. QSA v996 保留 shared cache 与输出/累加批处理，并新增 softmax 多头批处理。
3. KDA 仅接收已验证父文件 SHA，保留六个原编译宏并启用矩阵批处理宏。
4. 先运行独立、真实权重与变化输入图重放验证，再在四个服务 rank 接收模块。
5. 确认没有运行或等待请求，暂停、替换、重新捕获图，四个 rank 成功后恢复。
6. 使用 v7 协议直接选择 decode v984、prefill v995、QSA v991 与新 KDA，
   与 v5 父版本结果比较；v6 联合候选的 C1 回归，不作为最终选择。
7. 恢复时核验原 PID/创建时间，只处理本次拥有的失败或空闲进程树，保持容量设置。
   重新载入后执行文本请求，检查零 fallback、图状态正常和 API 未暂停。
