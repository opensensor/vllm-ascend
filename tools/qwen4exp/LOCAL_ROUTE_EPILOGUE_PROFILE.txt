Local down projection and fused route reduction, October 16, 2026 UTC

Qualified implementation
  The paired eager path skips zeroing the down projection's inactive output
  rows and never reads them in finalization. It preserves the existing local
  activation packing, frozen M32/M128 projection schedule, FP16 projection
  output, FP32 multiplication and original route order. Kernels read the final
  expert boundary on device; normal execution adds no route-count readback.
  No generic native_linear consumer receives an uninitialized output tail.

  CANN compiled both sources for dav-2002. The initial sequential reduction
  matched the retained NPU sum, but its 256-column tiles repeated scalar
  addressing and transfers. The revised kernel streams whole 2560-column
  weighted rows into an FP32 sum, starting at +0. Multiply and add remain
  separate. Its local storage is 25 KiB; no 200 MiB weighted-route tensor is
  materialized at 20480 routes. The pairwise tree failed exact equivalence and
  is rejected. Its presence in the private binary does not enable it in service.

  The opt-in paired_down callback in qfn_route_finalize replaces the complete
  activation/down/finalization/sum block through the existing source-hash guard.
  It requires eager-only execution and excludes other activation callbacks.
  The private adapter preserves the retained local pack, activation fallback,
  projection and finalizer for unsupported cases, short batches and graphs.
  Descriptors for both producer and consumer are admitted before submission.
  Failure after submission retains resources and forbids reuse or fallback.

Hardware correctness
  Four resident v16 workers borrowed their loaded model weights read-only.
  Requests were drained for private gates, with prefix caches, weights,
  graph owners and the resident patch generation preserved. No server restart,
  driver, firmware, launcher, OPP package or graph configuration changed.

  Each kernel revision passed 64 ordered and 68 sequential epilogue cases
  across four ranks: 130/650/5150/20480 routes, zero/one/quarter/full ownership,
  permutations, signed zero, half subnormals, large finite values and explicit
  cancellation. Inactive input tails were filled with NaNs. Pairwise passed
  only 32 of 68 cases and is not qualified. Numerical mismatch did not mutate
  model execution; the healthy workers resumed after each private gate.

  Both revisions passed 240 complete projection/finalization comparisons with
  first- and last-layer real down banks across all four ranks. Cases included
  zero, one, quarter, all-local and quarter-local skewed ownership at capacities
  650/5150/20480. Both revisions also passed 256 complete activation/packing/
  projection/finalization comparisons, including the short-batch fallback.

  Revised sequential serving shadows passed 624 comparisons per rank, 2496
  total, with zero mismatches. Workloads included pure prefill and an additional
  prefill while another request decoded. Shadows returned reference outputs.
  Shadow timings include duplicate computation/readbacks and are not speedups.
